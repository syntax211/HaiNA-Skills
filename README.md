# 🏗️ HaiNA Skills
### Open-Source AI Agent Skills for Construction Project Management

**Automating construction workflows with intelligent, reusable AI skills.**

HaiNA Skills is an open-source collection of AI Agent Skills focused on construction project management, engineering productivity, and construction workflow automation.

Developed and maintained by **HaiNA**, the project aims to help construction professionals automate everyday tasks using AI agents such as Hermes Agent, Claude Code, OpenAI Codex, and other compatible platforms.

## 🎯 Mission

Make advanced AI automation accessible to construction professionals through practical, reusable, and open-source skills.

Our objectives:

- Automate repetitive construction management tasks.
- Improve project reporting and documentation.
- Simplify scheduling, monitoring, and progress analysis.
- Transform site data and photographs into professional reports.
- Support engineering and project management workflows.
- Promote open-source AI adoption in the construction industry.

## 🤖 Compatible AI Agents

HaiNA Skills prioritizes:

- **Hermes Agent** — Primary integration and execution platform.
- **Claude Code** — Compatible skills and workflows.
- **OpenAI Codex** — Compatible skills and workflows.
- **Other AI Agents** — Where the skill format and runtime are supported.

Compatibility and required tools may vary by skill.

## 📁 Repository Organization

Each skill may be maintained in its own GitHub repository for independent development, releases, and installation.

This repository serves as the central catalog, documentation hub, and roadmap for HaiNA Skills.

Individual skills generally follow this structure:

```text
skill-name/
├── SKILL.md
├── README.md
├── scripts/
├── references/
└── assets/
```

Optional directories are included only when necessary.

## 🚀 Getting Started

1. Browse the Skills Library above.
2. Open the repository of your preferred skill.
3. Review its README, requirements, and `SKILL.md`.
4. Install it using your AI Agent's supported installation method.
5. Follow the skill's examples to execute your workflow.
